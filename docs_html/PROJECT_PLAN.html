HDFC Bank Loan Approval Prediction — Project Plan

1. Project Overview

Title: Loan Approval Prediction System for HDFC Bank Ltd. Subject: AI for Engineers Type: Supervised Machine Learning — Binary Classification Objective: Build a classification model that predicts whether a loan application should be Approved or Rejected based on applicant details such as income, credit history, employment status, and property area.

3. Dataset Details

Source: Kaggle — "Loan Prediction Dataset" (Analytics Vidhya / Dream Housing Finance) File: loan_data.csv Records: ~614 rows Target Variable: Loan_Status (Y = Approved, N = Rejected)

3.1 Feature Dictionary

# Column Type Description
1 Loan_ID String Unique loan reference ID (drop before training)
2 Gender Categorical Male / Female
3 Married Categorical Yes / No
4 Dependents Categorical 0, 1, 2, 3+
5 Education Categorical Graduate / Not Graduate
6 Self_Employed Categorical Yes / No
7 ApplicantIncome Numerical Income of applicant
8 CoapplicantIncome Numerical Income of co-applicant
9 LoanAmount Numerical Loan amount (in thousands)
10 Loan_Amount_Term Numerical Term of loan (in months)
11 Credit_History Numerical Credit history meets guidelines (1 = Yes, 0 = No)
12 Property_Area Categorical Urban / Semiurban / Rural
13 Loan_Status Categorical Y (Approved) / N (Rejected) — TARGET

5. Project Workflow (Step-by-Step)

Phase 1 — Data Collection & Understanding (Day 1-2)

  • Download dataset from Kaggle
  • Load into pandas DataFrame
  • Understand shape, dtypes, head/tail
  • Check for missing values (df.isnull().sum())
  • Check class distribution of Loan_Status

Phase 2 — Exploratory Data Analysis (Day 2-3)

  • Univariate analysis: histograms for numerical, countplots for categorical
  • Bivariate analysis: how each feature relates to Loan_Status
  • Correlation heatmap for numerical features
  • Box plots for outlier detection (ApplicantIncome, LoanAmount)
  • Key insight documentation

Phase 3 — Data Preprocessing (Day 3-4)

  • Handle missing values:
  • Categorical → fill with mode
  • Numerical → fill with median
  • Handle outliers using log transformation on ApplicantIncome, LoanAmount
  • Encode categorical variables:
  • Label Encoding for binary columns (Gender, Married, Education, Self_Employed, Loan_Status)
  • One-Hot Encoding / Label Encoding for Dependents, Property_Area
  • Feature engineering:
  • TotalIncome = ApplicantIncome + CoapplicantIncome
  • LoanAmountPerMonth = LoanAmount / Loan_Amount_Term
  • IncomeToLoanRatio = TotalIncome / LoanAmount
  • Drop Loan_ID column
  • Feature scaling using StandardScaler (for models that need it like SVM, Logistic Regression)
  • Train-test split: 80% train, 20% test (random_state=42)

Phase 4 — Model Building (Day 4-5)

  • Train the following models:
  • Logistic Regression (baseline)
  • Decision Tree Classifier
  • Random Forest Classifier
  • Support Vector Machine (SVM)
  • (Optional) XGBoost / Gradient Boosting
  • Use 5-fold cross-validation for each model
  • Record training accuracy and cross-validation accuracy

Phase 5 — Model Evaluation & Comparison (Day 5-6)

  • Evaluate on test set using:
  • Accuracy Score
  • Precision, Recall, F1-Score
  • Confusion Matrix
  • ROC-AUC Curve
  • Create comparison table of all models
  • Select best model based on accuracy + F1-score balance
  • Plot confusion matrices side-by-side

Phase 6 — Final Integration & Documentation (Day 6-7)

  • Clean up final notebook with markdown explanations
  • Save best model using joblib or pickle
  • (Optional) Build a Streamlit web app for live prediction
  • Prepare project report / PPT
  • Prepare for viva questions

9. Risk & Mitigation

Risk Mitigation
Small dataset (614 rows) — risk of overfitting Use cross-validation, avoid overly complex models
Missing values in critical columns Use median/mode imputation; document justification
Class imbalance (more Approved than Rejected) Monitor with precision/recall; consider SMOTE if needed
Team member delays Leader reviews daily; fallback = leader completes pending tasks
Viva — team member can't answer Leader's Viva Guide shared with all members 2 days before viva
